## I Love U Flávia ❤️

A small and personal website created as a special gift for my girlfriend.

This project was made with the intention of turning memories, feelings, and our relationship into an interactive digital experience. Instead of being just another website, it was designed to be something personal — a place that represents a little part of our story.

## 💌 About
This website was created specifically for someone very special to me.

It combines a simple and romantic design with interactive elements to create a unique experience. Every detail was thought out with the idea of making the website feel personal and meaningful.

The goal wasn't to build something technically complex.

The goal was to build something that means something.

## ✨ Features
* 💖 Romantic and personalized design
* 📱 Responsive layout
* 🎵 Music and audio elements
* 📸 Personal memories and moments
* 💌 Personalized messages
* 🌙 A visual experience designed around our relationship

## 🛠️ Technologies
* HTML5
* CSS3
* JavaScript

## 🎨 Design
The visual design was created around a romantic and intimate atmosphere, using soft colors, animations, photographs, and interactive elements to make the experience feel more alive.

Rather than following a generic template, the website was designed specifically for the person receiving it.

## 💭 Why I Made It
Sometimes a simple website can be more meaningful than an expensive gift.

I wanted to create something that could be kept, revisited, and remembered.

Every section represents a small part of what we have together, making the website more than just a coding project.

It is a digital representation of something much more important to me.

## 🚀 Running Locally
Clone the repository:

```bash
git clone <repository-url>
```

Open the project folder:

```bash
cd love-website
```

Then open `index.html` in your browser.
No backend or build process is required.
